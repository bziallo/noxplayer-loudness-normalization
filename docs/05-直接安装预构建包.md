## 1. 装进 Edge（三步）

1. 地址栏输入 `edge://extensions/` 回车；
2. 左下角打开 **开发人员模式**；
3. 点 **加载解压缩的扩展**，选这个目录（建议先把它复制到固定位置，比如 `D:\code\电闹播放器-响度归一\`，
   因为 **Edge 记住的是这个路径，之后不能移动或删除**）：

   ```
   C:\Users\<你的用户名>\Documents\Codex\2026-10-13\web-audio-typescript-b-b-b\outputs\noxplayer-edge
   ```

加载成功后列表里会出现「电闹播放器」。点工具栏图标（没显示就点地址栏右侧的拼图按钮固定它）→
它会**新开一个标签页**，播放器在这个页面里跑。

> ⚠️ 它和商店版是**两个不同扩展**（ID 不同 → 歌单数据各自独立）。商店版的歌单不会带过来；
> 想搬就用播放器里的同步/备份功能，或者直接卸载商店版只留这个。
>
> ⚠️ Edge 启动时可能提示「正在使用开发人员模式扩展」，这是未打包扩展的正常提示。

## 2. 打开响度归一

播放器页面顶部「**我的歌单**」那一行的右侧：随机播放、**齿轮**、问号 →
点**齿轮** → 「播放器设置」→「**设置**」标签 → 往下滚到「**响度归一（整段测量 + 固定增益）**」→ 勾上它。

默认档案是 **标准（−14 LUFS）**；同区块还能调目标响度/最大提升/最大衰减三个滑条、
勾「旁路」做 A/B、清空测量缓存，以及看一行状态：

```
命中缓存 · sidx · 实测 -18.7 LUFS · 目标 -14 LUFS · 增益 4.7 dB · 输出 gain-node
```

## 3. 验收（F12 控制台）

```js
noxLoudness.getLastStatus()        // 实测 LUFS / 目标 / 施加的增益 / 工作模式
noxLoudness.engine.getGainValue()  // 当前线性增益：安静段与高潮段各跑一次，值应几乎不变（= 常数增益，未压缩）
```

- 两首响度差很大的歌，一起丢进歌单连播 3–5 次 → 切换瞬间不应有明显跳变；
- 同一首里挑安静段/高潮段，按 `Shift+B` 旁路做 A/B → 两段的音量差应该一样大，只有整体平移；
- `mode` 应为 `gain-node`；若是 `volume` 说明降级了（只能衰减），把控制台 `[loudness]` 日志发我。

## 4. 这个包和「你自己构建」的差别（如实说明）

因为这个沙箱里没有 yarn、git 也连不上 GitHub，我用的是一套**等效替代链路**，功能上没差，但要知道：

| 项 | 我这份 | 你自己 `yarn build`（见 04 文档） |
|---|---|---|
| 依赖安装 | pnpm（1197 个包，版本与仓库声明一致；react/react-dom 已按仓库 `resolutions` 锁到 19.1.1） | yarn 4（官方方式） |
| 两个 `github:` 依赖 | 用仓库 pin 的**同 commit 源码**（`libmuse@942f16b`、`react-music-player@72760b4`），播放内核 fork 由我用仓库自带 babel 编译出 `lib/`+`es/` | yarn 自动 clone 并跑它的 prepare 构建 |
| `.env` | 拷贝 `.env.example` 的**占位值** → 云同步（Dropbox/Gitee/GitHub/个人云）不可用，其它功能正常 | 可填自己的 Key，云同步可用 |
| 运行时验证 | 只做了静态自检：manifest 引用的文件全部存在、bundle 里确认包含 `noxLoudness` / `createMediaElementSource` / `loudness-table` 标记 | 同样建议自己跑一遍 |

**我没法在这个环境里真的启动 Edge 点一遍**，所以音频链路（AudioContext 接管、抽样解码）
需要你装上后按 §3 确认一次。

## 5. 什么时候应该改用 04 文档自己构建

- 想把扩展名/版本改成自己的（做成独立扩展并存，而不是覆盖同名）；
- 想填 `.env` 让云同步可用；
- 想上架 Edge 加载项商店（商店要传**你自己的构建产物**，别用我这个沙箱包）；
- 想继续改代码（改完 `yarn build` + 点「重新加载」）。

那套流程见 [04-自用安装步骤.md](04-自用安装步骤.md)。这台机器上最省事的安装方式是 winget：

```powershell
winget install --id OpenJS.NodeJS.LTS -e
winget install --id Git.Git -e
winget install --id Python.Python.3.12 -e
```

（装完重开一个 PowerShell 窗口让 PATH 生效。）
