# 响度归一独占模式 · 使用说明

> 一句话：**打开这个开关，就保证只有「响度归一」一个系统在动音量。**

---

## 1. 它解决什么

可能同时在改音量的有三套东西：**播放器自己的处理**、**B 站网页端自带的音量均衡**、
以及**「B 站响度归一」油猴脚本**。三者叠加会出现「开口音量突变」「越调越小」「两个系统互相打架」。

打开独占模式后，播放器会让出全部话语权 ——

| 系统 | 独占模式下的状态 |
|---|---|
| 播放器的 ffmpeg 全片测量 | **不参与**（只保留抽样测量，绝不下载整片） |
| 旧的 `r128gain` 即时均衡（写元素音量） | **禁用**（设置里置灰） |
| B 站自带的响度增益元数据 | **忽略** |
| 「响度归一」 | 由它一个人决定 —— 施加**一个固定增益**，不做压缩 |

---

## 2. 怎么开

1. 播放器页面 → 顶部「我的歌单」右侧的**齿轮** → 「播放器设置」→「设置」；
2. 找到「**响度归一**」区块 → 勾选最上面的「**🔒 响度归一独占模式**」；
3. 页面右上角会出现标识：
   - **🔊 响度归一独占中** → 归一开着（推荐，音量一致但不压缩动态）；
   - **🔒 独占模式：原始输出** → 归一也关着，即**完全原始直出**。

两种组合的含义：

| 独占模式 | 响度归一 | 效果 |
|---|---|---|
| 关 | 关 | 播放器默认状态（不做任何处理） |
| 关 | 开 | 归一照常，但 B 站元数据增益 / ffmpeg 依然可能参与 |
| **开** | **开** | **推荐**：只有归一在动音量，一个固定增益，动态不受影响 |
| **开** | 关 | 音频**完全原始直出**：不测量、不改音量、不建 Web Audio 图 |

> 设置面板里那行「**当前生效的音频处理链**」会直接告诉你此刻谁在管音量。

---

## 3. 怎么验证它真的生效

在播放器页面按 `F12` → Console：

```js
noxLoudness.getLastStatus()      // 看 mode / engine / gainDb
noxLoudness.engine.getMode()     // 'gain-node' | 'volume' | 'off'
```

| 期望 | 说明 |
|---|---|
| 独占 + 归一开 → `mode: 'gain-node'`，日志里 `engine` **只会是 sidx** | 没有任何 ffmpeg 参与 |
| 独占 + 归一关 → `mode: 'off'` 且控制台**没有** `[loudness]` 测量日志 | 完全原始直出 |
| 设置里 `r128gain` 勾选框变成灰色不可点 | 旧均衡已被互斥 |

另外可以把 `Shift+B` 当作 A/B：旁路时输出原声，恢复时回到归一后的固定增益 ——
两者之间应当只有**整体平移**，没有随时间压动的痕迹。

## 4. 和油猴脚本 / B 站网页的关系（重要）

这两个「外部系统」在**扩展页面里其实不存在**，所以不需要、也无法在播放器内去关它们：

| 说法 | 实际情况 |
|---|---|
| 「关闭 B 站网页版自带的音量均衡」 | 播放器是 `chrome-extension://` 页面，**没有** bilibili.com 的播放器 DOM / `bpx_player_profile`，这项**不适用** |
| 「让 B 站响度归一脚本接管播放器里的音频」 | 油猴脚本的 `@match` 只有 `bilibili.com/video|list|bangumi`，**无法注入扩展页面** |

所以「独占模式」的实现方式是：**让播放器自己成为那个唯一的系统**（算法就是脚本同款，
已经移植进来），而不是去指挥别人。你在**网页版 B 站**看视频时，那套仍然由油猴脚本负责，
两边互不影响（不同页面、不同进程）。

---

## 5. 已知限制

- Web Audio 的 `MediaElementAudioSourceNode` **一个元素只能建一次、且不能撤销**。
  如果你在**同一次会话里先开过归一、再开独占**，音频图仍然存在 —— 此时独占会把增益固定为
  `1.0`（等于原始音量，数学上透明），但想拿到"一点弯路都不走"的绝对纯净，
  请在**开启独占后再重新加载扩展**（`edge://extensions` → 重新加载），这样它从一开始就不会建图。
- 独占模式下「测量方式」被锁定为**抽样测量**；对极少数没有分片索引的音频（例如 `durl` 试看片段），
  会保持原声而不是退化成 ffmpeg 全片测量。
- 独占模式不影响封面、歌词、播放进度等其它功能。
